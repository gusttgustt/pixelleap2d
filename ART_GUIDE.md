# Art Guide — replacing placeholder art with your own (Aseprite)

All art in the game is generated by code (`Assets/Scripts/PixelArt.cs`).
You can replace any sprite one at a time, and the rest keep working.

## Workflow

1. In Unity: menu **Island → Export Placeholder Art**.
   Every sprite is saved as a PNG in `Assets/Art/Placeholders/` at the correct size.
2. Open a PNG in **Aseprite** and repaint it. **Keep the same canvas size**: the "feet"
   (pivot) of the sprite stay in the same place relative to the canvas.
3. Export as PNG with **the same file name** into `Assets/Resources/Sprites/`
   (create the folder). Example: `Assets/Resources/Sprites/tree.png`.
4. Select the PNG in Unity and set:
   - Filter Mode: **Point (no filter)**
   - Compression: **None**
5. Press Play. The game uses your sprite automatically.

## Rules
- 1 tile = **32 × 16 px** (2:1 isometric diamond), 32 pixels per unit.
- Light comes from the **top-left**. The shadow is already drawn at the bottom of each sprite.
- Terrain height: each level raises the tile **6 px**.
- Use a limited palette (e.g. from lospec.com) so everything matches.

## Sounds
Sounds are generated in code (`Sfx.cs`). To replace one, put a `.wav`/`.ogg` in
`Assets/Resources/Sounds/` named: `pickup`, `chop`, `drink`, `eat`, `hurt`, `hit`,
`craft`, `splash`, `win`, `levelup`, `waves` (looping ambience).
